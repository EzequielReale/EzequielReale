### 🚀 Proyectos Destacados

- 🧠 **CasER 4.0**: Herramienta CASE web que genera el diseño conceptual, lógico y relacional de bases de datos a partir de requerimientos en lenguaje natural, conservando la trazabilidad completa entre etapas. Utilizada como recurso didáctico en grado y posgrado de la Facultad de Informática (UNLP), base de mi tesina y publicada en el ámbito científico. *(React, React Flow, Node.js, Express, MUI, Google Drive API)*.
- 🤖 **ALSINITO**: Bot de WhatsApp para gestión y despacho de asistencias mecánicas viales en tiempo real. Diseñado con flujos para choferes y mecánicos, reintentos automáticos, trazabilidad de entregas y arquitectura desacoplada del sistema principal mediante APIs REST. Fácilmente extensible a otras áreas de la organización *(Python, Django, MySQL, WhatsApp API)*.
- 🐴 **[CEDICA](https://github.com/EzequielReale/Proyecto-De-Software-2024-CEDICA)**: Sistema de gestión integral y portal público para el Centro de Equitación para Personas con Discapacidad y Carenciadas. *(Proyecto de Software UNLP)*.
